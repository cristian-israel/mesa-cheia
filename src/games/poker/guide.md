# Poker

Cada um no próprio placar. Baralho francês de **52 cartas**. Esta mesa não marca fichas — só o rumo da noite.

## Ranking das mãos

Da mais forte para a mais fraca. Empate de tipo: vale a carta mais alta (kicker). Naipe não desempata. O quadro está em **Anexos**.

## Modos

Na Mesa dá para escolher:

| Modo | Como funciona |
| --- | --- |
| **Sair um a um** | Quem quebrou sai. Conta mãos levadas. Ganha quem sobrar. |
| **Rodadas** | Só anota quem levou cada mão (sem placar). Marca quem **zerou** e, no fim, **quem venceu**. |

Este app só registra a mesa. Combinado (blinds, rebuy, all-in) continua na conversa.
